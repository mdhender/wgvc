# Desirability-field growth experiment

Issue #24 replaces inter-island distance rules with a static desirability field
and one-hop control. Issue #25 adds a permanent ocean barrier and a configurable
edge ramp. The experiment remains separate from the public generator while its
field shape and softmax behavior are calibrated.

The experiment builds the same relaxed, world-level Voronoi mesh as the current
generator. Any cell whose polygon enters the outer 0.02 map-unit strip is
permanently ineligible for land. Starting with the first eligible hop past that
barrier, the edge field defaults to `-1,-0.65,-0.40,-0.22,-0.10,-0.04,0` and
stays neutral beyond the end of the sequence. Multi-source propagation keeps
the harsher value where paths from different edges meet.

Twelve attractants add linearly fading positive influence within a radius of
0.18 map units. Values are clipped to `[-1, 1]`; attractants never make barrier
cells eligible.

Seeds are uniformly selected from unclaimed cells and use the same claim logic
as later growth. A claim controls previously uncontrolled neighboring cells.
The controller sees each such cell's static value, while rivals see -0.82.
Frontier selection uses a softmax with temperature 0.20.

Apart from the permanent edge barrier, there is no hard spacing or
water-connectivity filter. Every eligible, unclaimed frontier cell has nonzero
probability, so interior lakes remain valid outcomes.

Claiming a rival-controlled cell merges the islands only when that cell is
directly adjacent to the controller's claimed land. The winner receives all
claimed and controlled cells, and the loser leaves the deck. Final island IDs
are compacted after growth, so the rendered island count can be lower than the
initial count.

Run the default experiment with:

```sh
go run ./cmd/x24
```

This writes `x24.svg`. Water cells are shaded by static desirability; purple
rings mark attractants, dark dots mark surviving island seeds, and the darker
outer band is the permanent ocean barrier. Use `-edge-barrier` to tune its
width and `-edge-ramp` to supply a comma-separated ramp. Run
`go run ./cmd/x24 -h` for all calibration flags.
