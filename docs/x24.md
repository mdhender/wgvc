# Desirability-field growth

Issue #24 replaces inter-island distance rules with a static desirability field
and one-hop control. Issue #25 adds a permanent ocean barrier and a configurable
edge ramp. Issue #26 guarantees regional attractant coverage when the configured
ramps leave enough room. This algorithm now drives the public generator.
`wgvc-render` exposes its controls without expanding the public API.

The algorithm builds the same relaxed, world-level Voronoi mesh as the current
generator. Any cell whose polygon enters the outer 0.02 map-unit strip is
permanently ineligible for land. Starting with the first eligible hop past that
barrier, the edge field defaults to `-1,-0.65,-0.40,-0.22,-0.10,-0.04,0` and
stays neutral beyond the end of the sequence. Multi-source propagation keeps
the harsher value where paths from different edges meet.

The map is divided into 3×3 regions. The `-attractors` flag accepts 0, 1, 2, 3,
4, 5, 6, or 9 and defaults to 0. Counts 1 through 6 select regions in the same
pattern as pips on a six-sided die; 9 selects every region. Each selected region
gets a target near its center, jittered by the round RNG, and selects the nearest
cell that satisfies edge clearance. The default jitter is 0.65 of the distance
from a region center to its edge. If no cell in a selected region is far enough
from the map edge, that region is skipped and `wgvc-render` logs the reason without
restarting the round.

Attractants use a graph-hop ramp, defaulting to
`1,0.78,0.58,0.42,0.29,0.18,0.10,0.04,0.01,0`. A source must be more than the
sum of the edge and attractant ramp reaches from the barrier, proving that
positive attractant influence and negative edge influence cannot touch the same
cell. Overlapping attractants add together, with the completed field still
clipped to `[-1, 1]`.

Seeds are uniformly selected from unclaimed cells and use the same claim logic
as later growth. A claim controls previously uncontrolled neighboring cells.
The controller sees each such cell's static value, while rivals see -0.82.
Frontier selection uses a softmax with temperature 0.20.

Apart from the permanent edge barrier, there is no hard spacing or
water-connectivity filter. Every eligible, unclaimed frontier cell has nonzero
probability, so interior lakes remain valid outcomes.

A claim merges every rival island whose claimed land is directly adjacent to
the newly claimed cell. Control affects desirability but is not used as a proxy
for connectivity. The winner receives all claimed and controlled cells, and
each loser leaves the deck. Final island IDs are compacted after growth, so the
rendered island count can be lower than the initial count.

Render the default configuration with:

```sh
go run ./cmd/wgvc-render
```

This writes `world.svg`; use `-format png` or `-format both` for PNG output.
Pass `-aspect 16:9`, `-aspect 2.39:1`, or another width:height name to render a
rectangle. Output dimensions are derived from the land-province count,
effective ocean percentage, and aspect ratio. Maps retain the production
terrain fills, cell borders, and coastline. Use `-edge-barrier` to tune the
permanent ocean strip, `-attractors` to select the number of attractors,
`-edge-ramp` and `-attractant-ramp` to supply comma-separated ramps, and
`-attractant-jitter` to tune regional placement. Run
`go run ./cmd/wgvc-render -h` for all generation flags.
