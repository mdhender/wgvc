# Issue #23 single-mesh growth experiment

`cmd/x23` builds one relaxed Voronoi mesh, plants one seed per island, and
grows those islands concurrently while preserving a graph-distance water gap.
It is isolated from the production `wgvc.Generate` path under `internal/x23`.

The defaults are seed `0x0123456789abcdef`, 15 islands, 1,500 land provinces,
68% initial ocean, three hops between land and the map edge, and three hops
between different islands. The mesh starts from uniform random sites and
applies two Lloyd relaxation passes. Failed rounds add three percentage points
of ocean, capped at 95%, and regenerate the complete mesh from a deterministic
round-specific random stream.

Run the default experiment with:

```sh
go run ./cmd/x23
```

This writes `x23.svg`. Use `go run ./cmd/x23 -h` to see the calibration flags.
The command and internal packages are experimental; the public API and current
generator remain unchanged.
