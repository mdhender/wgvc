# Single-mesh growth calibration

Issue #23's single-mesh growth algorithm now powers the public `wgvc.Generate`
path. It builds one relaxed Voronoi mesh, plants one seed per island, and grows
the islands concurrently while retaining a connected ocean and a graph-distance
water gap.

`cmd/x23` remains as a calibration tool with controls that are intentionally not
part of the public `Config` API. Its defaults are seed `0x0123456789abcdef`, 15
islands, 1,500 land provinces, 68% initial ocean, three hops between land and
the map edge, and three hops between different islands. The public generator
uses those distances when possible, then falls back to one edge hop and two
island hops for tiny valid configurations that cannot satisfy three hops.

The mesh starts from uniform random sites and applies two Lloyd relaxation
passes. Failed rounds add three percentage points of ocean, capped at 95%, and
regenerate the complete mesh from a deterministic round-specific random stream.

Run the calibration command with:

```sh
go run ./cmd/x23
```

This writes `x23.svg`. Use `go run ./cmd/x23 -h` to see all calibration flags.
